1. Objetivo de la Práctica

Subir los ejercicios y evidencias de la clase del 23 de octubre correspondientes a la automatización con Ansible:

  1. Configuración del inventario gestionado y verificación de comunicación SSH ad-hoc con el módulo ping.
  2. Automatización de cuentas de usuario y permisos en el sistema con el playbook usuarios.yml.
  3. Despliegue automatizado del servidor web Apache mediante web.yml consumiendo la plantilla dinámica Jinja2 (index.html.j2).
  4. Implementación del reto de clase generando la página de monitoreo de salud del servidor.

2. Inventario y Conectividad Ad-Hoc

Archivo de inventario /root/devops2026/ansible/inventario.ini:

[nodos] nodo1 ansible_host=127.0.0.1 ansible_user=ansible

Validación de conectividad SSH con el usuario de automatización:

[root@localhost ansible]# ansible all -m ping nodo1 | SUCCESS => { "ansible_facts": { "discovered_interpreter_python": "/usr/bin/python3" }, "changed": false, "ping": "pong" }

  1. Se logró la configuración idempotente de la infraestructura sin intervención manual en el servidor.
