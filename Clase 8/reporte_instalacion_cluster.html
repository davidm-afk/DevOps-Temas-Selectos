1. Objetivo y Arquitectura del Clúster

Generar evidencia técnica de la instalación, inicialización y funcionamiento operativo de un clúster Kubernetes multi-nodo compuesto por:

  • Control Plane (Master): IP 192.168.71.128 ejecutando el API Server, etcd, scheduler y controller-manager.
  • Red de Pods (CNI Flannel): Subred 10.244.0.0/16 para la comunicación entre contenedores.
  • Capacidad de Cómputo: Ejecución de pods de sistema y aplicaciones de usuario expuestas a la red local.
